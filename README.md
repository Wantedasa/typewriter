# Typewriter Effect ⌨️

Type out a string character by character, then loop. Tiny, no deps.

## What it is
A typewriter text effect. It reveals a string one character at a time and loops with a pause. Handy for hero headlines or status lines. Pure JS with setInterval.

## Usage
```js
typewriter(el, text, speed)
```
